# Beauty Shop — Responsive E-commerce UI

A modern and responsive beauty shop interface built with **Next.js** and **React**.

This project was created as a practice project to improve my skills in building responsive layouts, reusable React components, and modern e-commerce interfaces.

## ✨ Features

* Fully responsive design for desktop, tablet, and mobile
* Modern and minimal beauty-focused UI
* Product grid layout
* Responsive sidebar navigation
* Mobile hamburger menu
* Product preview modal
* Promotional product sections
* Social media links
* Clean and reusable React components
* Optimized image handling with Next.js

## 🛠️ Technologies

* **Next.js**
* **React**
* **Tailwind CSS**
* **JavaScript**
* **Next.js Image**

## 📱 Responsive Design

The interface is designed to adapt to different screen sizes and provide a smooth experience across:

* 🖥️ Desktop
* 💻 Laptop
* 📱 Mobile
* 📲 Tablet

## 🎯 Purpose

The main purpose of this project was to practice:

* Building responsive layouts with Tailwind CSS
* Working with React components
* Managing component state with `useState`
* Creating reusable UI components
* Working with images in Next.js
* Designing modern e-commerce interfaces
